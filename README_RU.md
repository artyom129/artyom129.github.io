# Artyom Koncha — Developer Portfolio

[English](README.md) | **Русский**

Репозиторий статического портфолио, опубликованного через GitHub Pages:

https://artyom129.github.io/

Сайт сделан на семантическом HTML, CSS и небольшом количестве vanilla JavaScript.

## Локальный просмотр

Можно просто открыть `index.html` в браузере или запустить любой локальный static file server.

## Публикация

GitHub Pages раздаёт сайт напрямую из ветки `main` и корня репозитория. Отдельный build step и зависимости не требуются.
